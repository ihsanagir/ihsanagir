# LOU Adisyon — Garson Sipariş Defteri

LOU Cafe Bistro menüsü (fiyatlar: 01 Mayıs 2026) için telefonda çalışan dijital adisyon.
Kurulum yok: `index.html` dosyasını tarayıcıda açmanız yeterli (veriler cihazda saklanır).

## Kullanım
- **Masa seç** → sağ üstteki masa butonu (30 masa + özel isim: "Bahçe 3", "Paket – Ahmet").
- **Ürün yaz, Enter'a bas** — Türkçe karakter gerekmez (`turk kahv` → Türk Kahvesi).
  - `2 menemen` veya `menemen x2` → 2 adet
  - `sezar / sossuz` → mutfak notuyla ekler
  - `Doğum günü pastası = 500` → menü dışı ürün
  - ↑/↓ ile öneriler arasında gezin; kategori çiplerinden göz atın.
- Satıra dokun → adet, not, fiyat (ikram = 0) düzenle. `−`/`+` ile hızlı adet.
- **Mutfağa** → yeni (sarı) kalemleri gönderildi olarak işaretler.
- **Hesap** → indirim, kişi başı bölüştürme, nakit/kart, para üstü, adisyon yazdırma, masayı kapatma.
- **☰** → gün sonu ciro özeti (nakit/kart), kapanan hesaplar, tüm menü, garson adı, tema.

Menüyü güncellemek için `menu.js` dosyasındaki listeyi düzenleyin.
